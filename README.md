# ASX Investment Calculator

A responsive, zero-dependency Australian investment return and estimated CGT calculator with Brand Forest styling.

## Features

- Initial investment, purchase unit price and final unit price
- Units owned and final portfolio value
- Gross profit and percentage return
- Configurable estimated tax rate
- Optional 50% CGT discount
- Estimated CGT and net profit
- Responsive mobile and desktop design
- Runs entirely in the browser

## Hosting with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**.
4. Click **Save**.

The site will be available at:

`https://sugamnp.github.io/asx-calc/`

## Disclaimer

This calculator is a simplified estimate only and is not financial or tax advice. It excludes brokerage, carried-forward capital losses, other gains, Medicare levy and individual circumstances.
